# Политика безопасности

## Сообщение об уязвимостях безопасности

Сообщайте об уязвимостях безопасности через
[приватную систему сообщений об уязвимостях GitHub](https://github.com/qwen-code-dev-bot/oh-my-cli/security/advisories/new).

**Не включайте секреты, учетные данные или эксплойты в публичные Issues.**

## Процесс обработки

1. **Конфиденциальное сообщение**: Используйте систему приватных сообщений GitHub
   для всех уязвимостей безопасности
2. **Время ответа**: Мы стремимся ответить в течение 72 часов
3. **Исследование**: Мы исследуем все сообщения и поддерживаем открытую коммуникацию
4. **Исправление**: После подтверждения мы разрабатываем исправление
5. **Раскрытие**: Координируем публичное раскрытие после выпуска исправления

## Область действия

Эта политика безопасности охватывает:
- oh-my-cli CLI и его компоненты
- Desktop-версию (Electron)
- Официальные расширения и плагины
- Документацию и примеры кода в этом репозитории

## Что считается уязвимостью безопасности

- Несанкционированный доступ к файловой системе
- Утечка учетных данных или секретов
- Выполнение произвольного кода
- Обход механизмов безопасности
- Уязвимости в цепочке поставок

## Что не считается уязвимостью безопасности

- Проблемы с функциональностью (используйте обычные Issues)
- Вопросы производительности (используйте Discussions)
- Общие вопросы использования (используйте Discussions)
- Уязвимости в зависимостях, которые не затрагивают oh-my-cli

## Руководящие принципы ответственного раскрытия

1. **Не тестируйте в производственных средах**
2. **Не затрагивайте других пользователей**
3. **Предоставьте достаточно информации для воспроизведения**
4. **Будьте терпеливы с процессом исправления**

## Безопасные практики разработки

### Для пользователей
- Никогда не доверяйте непроверенным рабочим областям
- Используйте режим подтверждения по умолчанию для новых сред
- Регулярно обновляйте oh-my-cli до последней версии
- Проверяйте изменения перед применением

### Для разработчиков
- Все изменения файлов и команд оболочки требуют подтверждения
- Секреты всегда скрываются в выводе
- Опасные команды блокируются до явного разрешения
- Полный аудит всех действий сохраняется

## Контакты

Для вопросов безопасности, не являющихся уязвимостями, используйте:
- [Обсуждения GitHub](https://github.com/qwen-code-dev-bot/oh-my-cli/discussions)
- Issues с тегом `security-question`

## История исправлений

Исправления безопасности публикуются в релизах с тегом `[SECURITY]` в описании.
Все пользователи должны обновляться до последней версии для получения исправлений безопасности.
