## Что это?

**oh-my-cli** — это небольшой CLI с интеллектуальным агентом для работы с кодом, предоставляющий
инструменты для работы с файлами и командной оболочкой. Он построен на Node.js 22,
TypeScript и ESM. Его можно использовать как в интерактивном терминале,
так и для неинтерактивной автоматизации. Также доступна локальная версия Desktop
(Electron), предоставляющая графический интерфейс на той же системе сессий.

oh-my-cli — это агентное программирование, которое остаётся предсказуемым и
безопасным:

- **Безопасность по умолчанию** — инструменты для записи файлов и командной оболочки
  требуют подтверждения; опасные команды блокируются до явного разрешения
1. **Прозрачность** — вся работа агента полностью видима в логах инструментов и файлов
2. **Простая конфигурация** — только OpenAI-совместимые эндпоинты, без скрытых
   зависимостей или сложных конфигураций
3. **Продуктивность** — полезен как для быстрых задач, так и для полного
   цикла разработки
4. **Производительность** — полностью на TypeScript, не имеет зависимостей от
   Python или Rust для основной работы

CLI разработан для **индивидуальных разработчиков**, которым нужен быстрый
интерактивный помощник по программированию, и для **команд**, которым требуется
повторяемое, проверяемое поведение в разных репозиториях.

Английская документация является авторитетной версией. При несоответствиях между
английской и русской версиями документации приоритет имеет английская версия.

## Возможности

### 📁 Безопасность и контроль
- **Файлы и оболочка под контролем** — все инструменты записи файлов и командной
  оболочки требуют подтверждения (режимы `default`/`auto-edit`), если только вы
  явно не выберете `yolo`
- **Проверка безопасности команд** — идентификация опасных команд (удаление
  рекурсивных файлов, `sudo`, сброс `git --hard`) и блокировка до явного
  разрешения
- **Контроль рабочей области** — только явно доверенные рабочие области могут
  выполнять код или читать файлы `.env`
- **Аудит выполнения** — полный журнал того, что было вызвано, изменено и проверено
  с защитой от подделки

### 🚀 Интерактивное использование
- **Живой командный интерфейс** — интеллектуальное дополнение команд, `/команды`,
  просмотр сессий и управление нажатием клавиш
- **Возобновляемые сессии** — долгосрочные, продолжающиеся беседы, которые можно
  приостановить и возобновить по имени
- **Управление инструментами в реальном времени** — графический интерфейс для
  подтверждения, навигации и редактирования ожидающих действий

### 🤖 Автоматизация
- **Прямой вызов моделей** — одиночные, ограниченные, безопасные запросы к моделям
  для автоматизации сценариев
- **Вызов MCP** — безопасное выполнение инструментов MCP-сервера из автоматизации
- **Вызов инструментов** — ограниченные, безопасные вызовы пользовательских
  инструментов расширения
- **Мониторинг сессий** — список, поиск, фильтрация, статистика и экспорт
  сессий из командной строки

### 🔧 Инструменты разработчика
- **Проверка репозитория** — проверка готовности репозитория, просмотр контекста,
  карта файлов и ключевых символов
- **Планирование выполнения** — детерминированное, ограниченное планирование задач
- **Проверка изменений** — проверка и рецензирование изменений перед CI
- **CI-сдача** — составление проверки, рецензии и рукопожатия CI в завершающем
  отчете

### 🛡️ Политики и ограничения
- **Бюджет стоимости** — остановка до того, как оцененная стоимость достигнет
  лимита
- **Лимит ходов** — остановка после указанного количества раундов
- **Лимит времени** — остановка после истечения времени выполнения
- **Лимит вызовов инструментов** — остановка после достижения кумулятивного
  количества вызовов инструментов

## Быстрый старт

### Предварительные требования
- **Node.js 22 или новее**
- **npm 10.x или новее** (или другой менеджер пакетов)

### Установка
```bash
# Клонируйте репозиторий
git clone https://github.com/qwen-code-dev-bot/oh-my-cli.git
cd oh-my-cli

# Установите зависимости
npm install

# Соберите проект
npm run build

# (Опционально) Свяжите CLI для глобального использования
npm link
```

### Настройка модели
oh-my-cli работает с OpenAI-совместимыми эндпоинтами. Настройте переменные
окружения:

```bash
export OPENAI_API_KEY="ваш-ключ-api-здесь"
export OPENAI_MODEL="gpt-4o"
# или для совместимости с DashScope
export OPENAI_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
export OPENAI_MODEL="qwen-latest"
```

Или сохраните настройки в файле `~/.oh-my-cli/settings.json`:

```json
{
  "model": {
    "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "name": "qwen-latest",
    "apiKeyEnv": "DASHSCOPE_API_KEY"
  }
}
```

### Проверка установки
```bash
# Проверьте версию
oh-my-cli --version

# Запустите диагностику
oh-my-cli --doctor

# Проверьте подключение к провайдеру
oh-my-cli --preflight
```

### Первая задача
```bash
# Простой запрос
oh-my-cli -p "Перечисли файлы в этой директории"

# С обработкой изображений
oh-my-cli -p "Опиши это изображение" --image screenshot.png
```

## Запуск

### CLI режим
```bash
# Интерактивный режим (ожидает ввода в терминале)
oh-my-cli

# Однократный запрос
oh-my-cli -p "Ваш запрос здесь"

# С указанием рабочей области
oh-my-cli --workspace ./ваш-проект -p "Помоги с рефакторингом"

# С изображениями
oh-my-cli -p "Проанализируй схему" --image diagram1.png diagram2.png
```

### Desktop режим
```bash
# Запуск Desktop-версии
npm run desktop
```

Desktop-версия предоставляет графический интерфейс с теми же функциями,
что и CLI, включая управление сессиями, историю и инструменты.

### Режимы подтверждения
- **`default`** (по умолчанию) — подтверждение каждого инструмента записи файлов
  или командной оболочки
- **`auto-edit`** — автоматическое подтверждение изменений файлов, но подтверждение
  командной оболочки
- **`yolo`** — автоматическое подтверждение всего (только для доверенных сред)

```bash
# Изменение режима подтверждения
oh-my-cli --approval-mode auto-edit
```

## Конфигурация

### Файл настроек
Расположение файла настроек по умолчанию: `~/.oh-my-cli/settings.json`.

Пример полной конфигурации:
```json
{
  "model": {
    "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
    "name": "qwen-latest",
    "apiKeyEnv": "DASHSCOPE_API_KEY",
    "temperature": 0.1,
    "maxTokens": 8192
  },
  "approvalMode": "default",
  "providers": {
    "default": "dashscope",
    "dashscope": {
      "baseUrl": "https://dashscope.aliyuncs.com/compatible-mode/v1",
      "name": "qwen-latest",
      "apiKeyEnv": "DASHSCOPE_API_KEY"
    },
    "openai": {
      "baseUrl": "https://api.openai.com/v1",
      "name": "gpt-4o",
      "apiKeyEnv": "OPENAI_API_KEY"
    }
  },
  "tools": {
    "default": "core"
  },
  "mcp": {
    "default": "filesystem",
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/"]
    }
  }
}
```

### Переменные окружения
| Переменная | Обязательно | По умолчанию | Описание |
|---|---|---|---|
| `OPENAI_API_KEY` | Да | — | API-ключ для провайдера |
| `OPENAI_BASE_URL` | Нет | `https://api.openai.com/v1` | OpenAI-совместимый базовый URL |
| `OPENAI_MODEL` | Да | — | Имя модели для использования |
| `OMC_APPROVAL_MODE` | Нет | `default` | Режим подтверждения: `default`, `auto-edit`, `yolo` |
| `OMC_WORKSPACE` | Нет | Текущая директория | Рабочая директория |
| `OMC_SPEND_BUDGET_USD` | Нет | — | Бюджет в USD для остановки |
| `OMC_MAX_TURNS` | Нет | — | Максимальное количество ходов |
| `OMC_MAX_WALL_TIME` | Нет | — | Максимальное время выполнения |
| `OMC_MAX_TOOL_CALLS` | Нет | — | Максимальное количество вызовов инструментов |
| `NO_COLOR` | Нет | — | Отключить цветной вывод |

### Приоритет конфигурации
1. Аргументы командной строки (высший приоритет)
2. Переменные окружения
3. Файл настроек (`~/.oh-my-cli/settings.json`)
4. Файл `.env` в доверенной рабочей области (только для чтения)
5. Значения по умолчанию

## Использование

### Управление сессиями
```bash
# Список всех сессий
oh-my-cli --list-sessions

# Поиск сессий
oh-my-cli --list-sessions --filter "рефакторинг"

# Возобновление сессии
oh-my-cli --resume сессия-123

# Статистика сессии
oh-my-cli --session-stats сессия-123

# Экспорт сессии
oh-my-cli --export-session сессия-123 --out ./экспорт

# Сжатие сессии
oh-my-cli --compact сессия-123
```

### Инструменты разработки
```bash
# Проверка готовности репозитория
oh-my-cli --readiness

# Контекст репозитория
oh-my-cli --repo-context

# Карта репозитория
oh-my-cli --repo-map

# Планирование задачи
oh-my-cli --plan "Добавить аутентификацию пользователей"

# Проверка изменений
oh-my-cli --review-change --base origin/main

# CI-сдача
oh-my-cli --ci-handoff --base origin/main
```

### Работа с расширениями
```bash
# Обнаружение расширений
oh-my-cli --discover-extensions

# Совместимость ра��ширений
oh-my-cli --extension-compat

# Контракт MCP
oh-my-cli --mcp-contract --server filesystem

# Вызов MCP
oh-my-cli --invoke-mcp --server filesystem --mcp-tool read_file --mcp-arg path=/etc/hosts

# Контракт инструмента
oh-my-cli --tool-contract

# Вызов инструмента
oh-my-cli --invoke-tool --tool example --invoke-timeout 10000
```

### Автоматизация
```bash
# JSON вывод для автоматизации
oh-my-cli -p "Перечисли файлы" --output json

# Сводка выполнения
oh-my-cli -p "Задача" --summary

# Сохранение сводки
oh-my-cli -p "Задача" --summary-out ./результат.json

# Сравнение производительности
oh-my-cli --baseline base.json --candidate candidate.json
```

## Безопасность

### Политика безопасности
См. [SECURITY.md](SECURITY.md) для получения информации о сообщении об уязвимостях.

### Ключевые принципы безопасности
1. **Никаких секретов в выводе** — ключи API и секреты всегда скрываются
2. **Подтверждение мутаций** — изменения файлов и команды оболочки требуют подтверждения
3. **Ограничение рабочей области** — доступ только к явно доверенным директориям
4. **Проверка команд** — опасные команды блокируются до явного разрешения
5. **Аудит выполнения** — полная запись всех действий

### Доверие рабочей области
По умолчанию oh-my-cli не доверяет рабочей области. Чтобы разрешить чтение `.env`
или выполнение кода:

```bash
# Однократное доверие
oh-my-cli --trust -p "Задача"

# Постоянное доверие (запись в .trusted)
oh-my-cli --trust-workspace -p "Задача"
```
